# Cram

[English](README.md) | 한국어

**무엇이든 퀴즈로 바꿔보세요.**

분명 읽을 땐 알겠는데, 막상 설명하려면 기억이 안 날 때 있죠.
다시 읽자니 어디를 모르는지 모르겠고, 직접 문제를 만들자니 번거롭고요.

Cram은 그럴 때 쓰는 AI 에이전트 스킬이에요. 정리해 둔 노트나 문서, 웹 링크를 주면
공부할 내용을 퀴즈로 만들어줘요. 직접 풀어보면서 헷갈리는 부분을 찾고,
틀린 문제만 골라 다시 공부할 수 있어요.

완성된 퀴즈는 HTML 파일 하나로 저장돼요. 인터넷 없이도 열 수 있고,
친구나 팀원에게 파일만 보내주면 같이 풀어볼 수 있어요.

**[어떤 느낌인지 먼저 풀어보기 →](https://sjquant.github.io/cram/examples/http-caching-essentials.html)**
설치 없이 바로 열려요. 예제 퀴즈는 영어예요.
**[내 퀴즈 만들기 ↓](#첫-퀴즈-만들기)**

![Cram 사용 흐름: 플래시카드를 요청하고 퀴즈에서 정답을 확인하며 복습하기](docs/demo.gif)

예제가 어떻게 만들어졌는지 궁금하다면 [카드 데이터](examples/http-caching-essentials.json)를
살펴보세요. 저장소를 내려받았다면 [HTML 파일](examples/http-caching-essentials.html)을
직접 열어도 돼요.

## Cram, 이런 점이 좋아요

1. **공부할 자료만 있으면 돼요.** 문제를 하나씩 만들 필요 없이, 평소 쓰는 AI
   에이전트에 자료와 함께 퀴즈를 만들어 달라고 요청하세요. Cram 스킬이 문제 만들기부터
   브라우저에서 열 수 있는 파일로 저장하기까지 도와줘요.
2. **아는 문제는 넘기고, 틀린 문제만 다시 풀어요.** 답을 떠올린 뒤 정답을 보고
   직접 채점할 수 있어요. 한 번 다 풀고 나면 틀린 문제만 모아서 다시 도전해보세요.
   브라우저에 진도가 저장돼서 중간에 닫아도 이어서 공부할 수 있어요.
3. **파일 하나면 어디서든 복습할 수 있어요.** 문제와 퀴즈 화면이 HTML 파일 하나에
   들어 있어요. 퀴즈를 풀 때는 인터넷도, 회원가입도, 별도 앱 설치도 필요 없어요.
   공유받은 사람도 브라우저로 파일을 열기만 하면 돼요.

## 첫 퀴즈 만들기

퀴즈를 만들 때는 Cram을 지원하는 AI 에이전트와 컴퓨터에 설치된 `python3`가 필요해요.
Python 패키지를 따로 설치할 필요는 없어요.

### 1. 스킬 설치하기

**Claude Code**를 쓴다면 아래 두 줄을 차례로 입력하세요.

```text
/plugin marketplace add sjquant/cram
/plugin install cram@cram
```

**다른 AI 에이전트**를 쓴다면 터미널에서 아래 명령을 실행하고, 사용하는 에이전트를 고르세요.

```sh
npx skills add sjquant/cram --skill cram
```

이 방법으로 설치하려면 `npx`를 실행할 수 있도록 Node.js/npm이 설치되어 있어야 해요.
[다른 설치 방법 ↓](#다른-설치-방법)

### 2. 내 자료로 퀴즈 부탁하기

작업 폴더에 공부할 내용을 `notes.md`로 저장하고, Claude Code에 이렇게 말해보세요.

```text
/cram:cram ./notes.md를 읽고 핵심 개념을 확인할 수 있는 플래시카드 10개를 만들어줘.
카드와 플레이어는 한국어로 만들고, 퀴즈를 study.html로 저장해줘.
```

다른 에이전트에서는 “cram 스킬로 ./notes.md를 읽고 핵심 개념을 확인할 수 있는
플래시카드 10개를 만들어줘. 카드와 플레이어는 한국어로 만들고, 퀴즈를 study.html로
저장해줘.”라고 요청하면 돼요.
내용을 그대로 붙여넣거나 문서를 첨부해도 좋아요. 웹 링크도 괜찮고요.
다만 사용하는 에이전트가 해당 자료를 읽을 수 있어야 해요.

### 3. 퀴즈 열기

완성된 `study.html`을 브라우저로 열면 바로 시작할 수 있어요.
문제를 보고 답을 떠올린 다음, 정답을 확인하고 채점해보세요.
다 풀고 나면 결과를 확인하거나 틀린 문제만 다시 풀 수 있어요.

파일을 보관해 뒀다가 다시 열어도 되고, 다른 사람에게 보내도 돼요.
내 진도와 점수는 브라우저에만 저장돼요. 파일을 보낸다고 함께 전달되지는 않아요.

## 이런 자료로 공부해보세요

- **새로 읽은 기술 문서:** 읽으면서 이해한 개념을 혼자서도 설명할 수 있는지 확인해보세요.
  위 예제에서는 HTTP 캐싱을 공부할 수 있어요.
- **시험 전 강의 노트:** 정리한 내용을 퀴즈로 만들면 어느 부분을 더 봐야 할지 확인하기 좋아요.
- **새 팀원을 위한 업무 가이드:** 알아두면 좋은 내용을 퀴즈로 만들어 팀원에게 보내보세요.

## 나에게 맞게 공부하기

직접 답을 떠올리는 문답형부터 객관식, 빈칸 채우기까지 만들 수 있어요.
힌트나 해설이 필요하면 퀴즈를 만들 때 함께 요청하세요.
마우스 대신 키보드로 조작할 수 있고, 화면의 움직임을 줄이거나 고대비 모드를 쓸 수도 있어요.

<details>
<summary>학습 순서, 진도 저장, 키보드 설정</summary>

설정의 학습 순서 메뉴에서 **Shuffle**을 누르면 문제 순서를 섞어서 다시 풀 수 있어요.
정답은 다시 가려지고, 이전 채점 기록은 남아요. **Restore original order**를 누르면
원래 순서로 돌아가요. 틀린 문제를 다시 푸는 중이라면 그 문제들 안에서만 순서가 바뀌어요.
메뉴 이름은 영어 화면 기준이에요.

진도 저장에는 브라우저 저장 공간을 사용해요. 저장이 허용되어 있으면 문제 순서,
풀던 위치, 점수, Cram 모드에서 반복해서 푼 기록이 남아요.
이어서 풀 때는 같은 브라우저로 같은 퀴즈를 열어주세요.
문제 내용이 바뀐 퀴즈는 처음부터 시작해요.

A/H 단축키가 불편하면 설정에서 끌 수 있어요. 브라우저 저장이 허용되어 있으면
다음에도 같은 설정이 유지돼요.

</details>

### 한국어로도 쓸 수 있어요

퀴즈 화면은 영어, 한국어, 일본어, 중국어 간체, 스페인어, 프랑스어를 지원해요.
에이전트에 “플레이어는 한국어로 만들어줘”라고 요청하면 돼요.
화면 언어를 바꿔도 문제까지 번역되지는 않으니, 문제도 한국어로 원한다면 함께 말해주세요.

## 다른 설치 방법

<details>
<summary>skills 설치 도구에서 에이전트 지정하기</summary>

[`npx skills`](https://github.com/vercel-labs/skills)는 지원하는 에이전트의 스킬 폴더에
Cram을 설치해줘요. 에이전트를 직접 고르려면 아래처럼 `--agent` 뒤에 이름을 넣으세요.

```sh
npx skills add sjquant/cram --skill cram \
  --agent codex \
  --agent cursor \
  --agent github-copilot \
  --agent grok \
  --agent kiro-cli \
  --agent antigravity-cli
```

</details>

<details>
<summary>Codex와 GitHub Copilot 마켓플레이스 명령</summary>

Codex:

```text
codex plugin marketplace add sjquant/cram
codex plugin add cram@cram
```

GitHub Copilot:

```text
copilot plugin marketplace add sjquant/cram
copilot plugin install cram@cram
```

</details>

Cram 스킬 파일은 `skills/cram/` 폴더에 있어요. 문제를 만드는 과정이나 데이터 형식,
HTML 생성 방법이 궁금하다면 [스킬 가이드](skills/cram/SKILL.md)를 참고하세요.
이 문서는 영어로 되어 있어요.

## 사용 전에 알아두세요

- **만들 때는 AI 에이전트가 필요해요.** 자료를 읽고 Python 스크립트를 실행할 수 있어야
  해요. 계정이나 이용 요금, 자료 접근 권한과 데이터 처리 방식은 쓰는 에이전트와 모델에 따라 달라요.
- **풀 때는 브라우저만 있으면 돼요.** HTML 파일에 문제와 퀴즈 화면이 모두 들어 있어서
  서버를 띄우거나 인터넷에 연결할 필요가 없어요.
- **정답도 한 번 확인해주세요.** Cram은 파일을 만들기 전에 카드 데이터의 형식이 맞는지
  검사해요. 내용이 사실인지까지 확인하는 건 아니에요. AI가 만든 문제와 정답은 원본 자료와
  함께 확인해주세요.
